Prepare the switch captures

  1. Use one main text file per fabric containing alishow. Fabric A on its own is fine.
  2. In PuTTY, increase scrollback first: Window > Lines of scrollback, use at least 20000; use more for large fabrics.
  3. Start logging to a plain text file before running the commands. Leave a blank line between command outputs if you are pasting manually.
  4. Run switchshow on each switch in the fabric, then run alishow once. If you only have one switch now, load that file first and add the other switch's switchshow output later in the additional switchshow panel.
  5. The optional extra command that makes NPIV port mapping easier is nsshow, especially where switchshow only says 1 N Port + X NPIV public.
  6. Do not edit out the switchName, zoning: ON (...), Defined configuration, or Effective configuration lines.
